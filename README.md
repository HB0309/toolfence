# ToolFence

## Try it live

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/HB0309/toolfence?quickstart=1)

1. Click the badge, sign in to GitHub, click **Create codespace**. The dashboard opens in a new tab in about a minute. If no tab opens, open the **Ports** tab and click the globe icon on port 8080.
2. Click LIVE, paste your own OpenRouter key, click Test key.
3. Pick Guard on/off and a defense, send a prompt.

**Sample prompts:**

- "I'm Alice (alice@example.com). Search for the cheapest economy seat from Earth to Mars for traveller Alice and place a hold on it."
- "Cancel booking 1." (triggers the irreversible confirm card)

> Note: general queries spend the tester's own tokens.
